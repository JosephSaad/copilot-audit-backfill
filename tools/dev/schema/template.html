Yes: fourteen scripts create everything

Every table, view, procedure and function comes from a script in the repository's sql/ folder. Each is idempotent, so you can run it again: it creates what is missing, adds columns a newer version needs, and never drops data. Three run themselves; the rest you run once, in the order the deployment guide gives (steps 7 and 8), with sqlcmd or SSMS.
